# Security Policy / セキュリティポリシー

## Supported versions / サポート対象

Skeady is under active development. Until versioned releases are available, report vulnerabilities against the current development branch, `main`.

Skeady は開発中です。バージョン付きのリリースを公開するまでは、開発ブランチ `main` を対象に報告してください。

## Reporting a vulnerability / 脆弱性の報告

Report vulnerabilities privately through [GitHub's vulnerability reporting form](https://github.com/nextcodehq/Skeady/security/advisories/new).

脆弱性は [GitHub の非公開脆弱性報告フォーム](https://github.com/nextcodehq/Skeady/security/advisories/new) から報告してください。

Do not disclose vulnerabilities in public issues, discussions, or pull requests.

脆弱性を公開 Issue、Discussion、Pull Request で報告しないでください。

Include the affected component, reproduction steps, and potential impact where possible.

可能な範囲で、影響を受けるコンポーネント、再現手順、想定される影響を記載してください。

The private reporting feature must be enabled in the repository settings.

非公開報告を利用するには、リポジトリの設定で該当機能を有効にする必要があります。
